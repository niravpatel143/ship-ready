# SEC020: SQL injection via string interpolation

## Why it matters
Interpolating user input directly into SQL strings bypasses query binding and allows
attackers to extract data, modify records, or drop tables.

## How to fix
Use parameter binding:

    // Bad
    DB::select("SELECT * FROM users WHERE name = $name");

    // Good
    DB::select("SELECT * FROM users WHERE name = ?", [$name]);
