# INF002: .env file copied into Docker image

## Why it matters
If COPY .env . is in your Dockerfile, production secrets are baked into the image layer.
Anyone with image registry access or who can run docker history can extract them.

## How to fix
Remove the COPY .env line and add .env to .dockerignore:

    .env
    .env.*

Inject environment variables at runtime via Docker Compose env_file, Kubernetes secrets,
or your platform secret manager.
