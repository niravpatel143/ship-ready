# SEC001: Debug Mode Enabled in Production

**Severity:** Critical  
**Category:** Security  
**Production Only:** Yes

## Why This Matters

When `APP_DEBUG=true` is set in production, Laravel displays detailed error pages that include:

- Full stack traces exposing your application's file structure
- Environment variables (including `APP_KEY`, database credentials, and API keys)
- Request/response data
- Loaded configuration values

An attacker can trigger errors to extract these details and use them to compromise your application.

## How to Fix

Set `APP_DEBUG=false` in your production `.env` file:

```env
APP_DEBUG=false
```

Ensure your deployment pipeline does not copy development `.env` files to production.

## Additional Notes

- Debug mode is safe in local development environments
- For detailed error reporting in production, use a service like Sentry, Bugsnag, or Flare
- Laravel's `APP_ENV=production` does NOT automatically disable debug mode — you must set `APP_DEBUG=false` explicitly
