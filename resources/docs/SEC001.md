# SEC001: Debug mode enabled in production

## Why it matters
When APP_DEBUG=true in production, Laravel exposes full stack traces and environment
variables in error responses. Attackers use this to map your codebase, discover leaked
credentials, and craft targeted exploits.

## How to fix
Set APP_DEBUG=false in your production .env file and use a dedicated error tracker
such as Sentry, Flare, or Bugsnag to capture exceptions without exposing them.
