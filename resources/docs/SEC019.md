# SEC019: Hardcoded secret or API key detected

## Why it matters
Hardcoded credentials in source code are committed to version control where they can be
exposed via repository access, leaked in logs, or accidentally shared.

## How to fix
Move secrets to environment variables and access them via config():

    $client = new StripeClient(config("services.stripe.secret"));

Add to .env: STRIPE_SECRET=sk_live_abc123...
