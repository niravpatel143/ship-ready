# QUE002: HTTP call in queued job without retry

## Why it matters
HTTP calls to external services fail transiently (timeouts, 5xx errors, rate limits).
A queued job without retries silently fails with no alerting and the work is lost.

## How to fix
Set tries and backoff on your job:

    class SendWebhookJob implements ShouldQueue
    {
        public int $tries = 3;
        public int $backoff = 60;
    }
