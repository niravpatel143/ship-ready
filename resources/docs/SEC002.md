# SEC002: Application Key Missing or Insecure

**Severity:** Critical  
**Category:** Security

## Why This Matters

The `APP_KEY` is used by Laravel to encrypt cookies, session data, and other sensitive values. If:

- It is missing, all encryption will fail or use an empty key
- It is shorter than 32 bytes, the encryption is cryptographically weak
- It is a placeholder/example value, it is likely shared across many applications

## How to Fix

Generate a fresh application key:

```bash
php artisan key:generate
```

Ensure each environment has its own unique key stored securely in `.env`.
