# LW001: Livewire public ID property without #[Locked]

## Why it matters
In Livewire v3 public properties are wire:model-bindable by default. A public $postId
can be manipulated by the client to reference any record ID, enabling IDOR attacks.

## How to fix
Mark non-bindable properties with the Locked attribute:

    use Livewire\Attributes\Locked;

    class EditPost extends Component
    {
        #[Locked]
        public int $postId;
    }
