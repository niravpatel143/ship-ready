# OCT001: Singleton capturing request in Octane

## Why it matters
Under Laravel Octane the application container is reused across requests. A singleton
that calls request() or Auth::user() at bind-time captures the first request data.
All subsequent requests receive stale data, leaking authentication state between users.

## How to fix
Never resolve request-scoped values inside singleton closures. Inject request as a
method argument or resolve it lazily inside service methods instead of the constructor.
