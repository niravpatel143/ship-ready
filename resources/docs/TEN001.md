# TEN001: Eloquent model missing tenant scope

## Why it matters
In multi-tenant applications every tenant-owned model must filter by the current tenant.
Without it a tenant can query another tenant data causing full data isolation failure.

## How to fix
With stancl/tenancy, add BelongsToTenant to your model:

    use Stancl\Tenancy\Database\Concerns\BelongsToTenant;

    class Post extends Model
    {
        use BelongsToTenant;
    }
