# INF001: Docker container running as root

## Why it matters
Running as root inside a container means a container escape or RCE gives the attacker
root privileges on the host. Drop to a non-root user to make process isolation effective.

## How to fix
Add a USER directive near the end of your Dockerfile:

    RUN addgroup --system app && adduser --system --ingroup app app
    USER app
